MISSING DEFINITIONS AND UNLINKABLE REFERENCES
=============================================

Re-verified against the working tree. Each entry is a result the text invokes by
name, where I then checked by hand whether any titled environment anywhere in the
repository actually states it, and whether that statement is reachable from the
citing document.

Of the 5,927 \hyperref citations in the repository, exactly two fail to resolve, and
both are listed in section 2 below. Everything else resolves. So the entries below
are gaps in the notes, not broken links.


1. NEVER STATED ANYWHERE
-------------------------
Cited as if already known; no environment in the repository states them. Each needs
a theorem (or definition) written for it.

  Parseval's theorem        Math/Univariate_Analysis/sec/analytic_functions.tex:215
  Fejer's theorem           Math/Univariate_Analysis/sec/analytic_functions.tex:277
  Stirling's formula        Math/Univariate_Analysis/sec/analytic_functions.tex:333
  Newton's identity         Math/Univariate_Analysis/sec/reals.tex:1333
      Introduced mid-proof ("We introduce Newton's identity ...") inside the
      induction for the binomial theorem, but never stated as its own result.
  Baire's theorem           Math/Univariate_Analysis/sec/sequences.tex:1255
      All five are cited from inside exercises -- "Deduce from Parseval's theorem
      that ...", "and hence prove Fejer's theorem", "Prove Baire's theorem" -- so
      those exercises are not self-contained: the result the student is asked to
      use or prove is never stated.

  Jacobi identity           Math/Linear_Algebra/sec/vector_spaces.tex:888
                            Math/Abstract_Algebra/sec/lie_groups_algebras.tex:1396
      The identity appears as an unnamed clause inside the Lie algebra definition
      but is never stated as its own result, so citations cannot point at it.
      Searching for "Jacobi" finds only \definition[Jacobian], a different object.

  Kolmogorov's theorem      Math/Probability_Theory/sec/laws_of_large_numbers.tex:471
      In a law-of-large-numbers section this presumably means the three-series
      theorem or Kolmogorov's SLLN. The repository has Chapman-Kolmogorov and the
      Kolmogorov cycle condition, both in Stochastic_Processes and both unrelated.

  Barrow's formula          Math/Ordinary_Differential_Equations/paper.tex:408

  Bareiss algorithm         Math/Linear_Algebra/sec/matrices.tex:452
  Gauss Elimination algo.   Math/Linear_Algebra/sec/matrices.tex:1356
  Vigenere algorithm        Math/Number_Theory/paper.tex:2180
      Algorithms named but never specified. `algo` environments exist elsewhere in
      the repository and would be the natural home.


2. STATED ONLY IN A FILE THAT NO DOCUMENT INCLUDES
---------------------------------------------------
These do have a statement, but it lives in Math/Linear_Algebra/sec/tbd.tex, which
no paper.tex \include's (see flaws.txt C3). The statement therefore appears in no
PDF, and the citations below have nothing to point at. Including that file, or
moving these two results into a file that is included, fixes both at once.

  Perron's theorem          cited  Math/Stochastic_Processes/sec/markov_processes.tex
                            stated Math/Linear_Algebra/sec/tbd.tex:177 [Perron's Theorem]
                                   and :318 [Frobenius Extension to Perron]
      The citation is a hand-written numeric cross-reference -- "The Frobenius
      Extension to Perron's theorem (Linear Algebra, Theorem 7.31) combined with
      its applications to stochastic matrices (Linear Algebra, Theorem 7.30)".
      (There used to be a second, identical copy in Probability_Theory; it went
      away when the Markov material was merged into Stochastic_Processes.)
      Because tbd.tex is not included,
      Theorems 7.30 and 7.31 do not exist in the Linear Algebra PDF, so these
      numbers point at nothing. They are also plain text, not \hyperref, so they
      will not be caught by any reference check and will silently drift if the
      numbering changes.

  Baker-Campbell-Hausdorff  cited  Math/Linear_Algebra/sec/vector_spaces.tex:874
    formula                        Math/Ordinary_Differential_Equations/paper.tex:2737
                            stated Math/Linear_Algebra/sec/tbd.tex
                                   [Trace of the Baker-Campbell-Hausdorff Series]
      Note that even if the file were included, only the *trace* of the BCH series
      is stated there, not the formula itself.

  MSE loss                  cited  Statistics/Linear_Regression/sec/ols.tex:3
                            stated Statistics/Frequentist_Inference/sec/bias_variance.tex:113
                                   [Mean Squared Error Loss]  \label{mse_loss}

  Bias-variance decomp.     cited  Statistics/Linear_Regression/sec/ols.tex:159
    of the expected MSE     stated Statistics/Frequentist_Inference/sec/bias_variance.tex:222
                                   [Bias Variance Decomposition of Expected MSE Loss]
                                   \label{bias_variance_mse}
      These are the only two \hyperref citations in the repository that currently
      point at nothing. Both statements exist and are perfectly good; the problem
      is that Statistics/Frequentist_Inference/paper.tex:336 reads
      "% \include{sec/bias_variance}" -- the include is commented out, so the whole
      file is absent from the PDF and `xr-hyper` exports no labels for it. Removing
      the comment fixes both citations at once (see flaws.txt C3, which lists this
      file among the eight orphaned Frequentist_Inference sections).

      Separately, these two labels do not follow the repository's labelling
      convention: they are `mse_loss` and `bias_variance_mse` rather than
      `def:...` / `thm:...`. I left them as-is so the existing citations keep
      working; renaming them means touching both files together.

                            stated Math/Linear_Algebra/sec/spectral_theory.tex
                                   [Spectral Theorem of Self-Adjoint Maps]

                            stated Math/Linear_Algebra/sec/inner_products.tex
                                   [Cauchy-Schwarz Inequality]
      Point_Set_Topology is upstream of Linear_Algebra.
